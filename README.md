# ねこタワー

変な形の猫画像を器に落として詰める、軽量なブラウザゲームです。
https://nekotower.isikoro.dev/

## 起動

PowerShell でこのフォルダを開いて実行します。

```powershell
.\serve.ps1
```

その後、ブラウザで http://127.0.0.1:4173/ を開きます。

静的ファイルだけで動くので、`index.html` を直接開いても動作します。

## 操作

- `A` / `D` またはマウス・ドラッグ: 猫を左右に移動
- `Q` / `E`、左右キー、回転ボタン: 回転
- マウスホイール: 回転
- `Space` / `落とす` / 左クリック: 落下
- ひとり用: 器から落とさずに入った猫の数を競う
- 対戦: 自分の番で猫を器から落とした人が負け

## メモ

Matter.js の物理演算を使っています。猫画像は `assets/trimcats` の透過PNGを読み込み、アルファ輪郭から生成した多角形を当たり判定に使います。

当たり判定を見たい場合は `?debugHit=1` を付けて起動します。

## 画面デザイン

`styles.css`は既存の基礎スタイル、`theme.css`は2026-11-24の外観調整。
ゲームの物理・座標・オンライン同期は変更していない。
旧表示へ戻す場合は`index.html`の`theme.css`読み込み行を削除してコミットする。
変更前の退避ブランチは`backup/before-ui-refresh-20261124`。
ボタンのIDは入力処理から参照されるため変更しない。

## CPU対戦とオンライン待機

タイトルの「CPU対戦」で、人間先手の交互対戦を開始する（お椀ステージ）。
自分の番で猫が場外に落ちると負け。CPUは自動で移動・回転・落下する。
オンライン対戦を選ぶと、マッチ待ち中はCPUと対戦できる。
マッチ成立時にCPU戦からオンライン対戦へ自動で切り替わる。
「待機をやめる」でオンライン待機だけを取り消し、CPU戦を続けられる。
CPU戦で勝敗がついても待機は続き、「リトライ」でCPU戦を再開できる。
