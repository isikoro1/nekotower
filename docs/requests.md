# ユーザー要求の記録

2026-11-24。このリポジトリに関係する会話から、継続開発に必要な要求を記録する。
会話全文・無関係な個人情報は含めない。確定した仕様はspec.mdに反映する。

## 外観

- ねこタワーをおしゃれに整える。
- 「キャッチコピーみたいなのは恥ずかしくて苦手」。宣伝文句を増やさず、簡潔にする。
- ねこ素材を主役に、背景・スコア・操作ボタンを整理する。
- 気に入らない場合にすぐ戻せるよう、変更前を保存する。

## CPU対戦・待機中の遊び

元の要求:

> マッチの間はCPUと対戦できるようにしてほしい。CPU対戦モードを搭載してほしい。
> プロンプトに関する指示書や仕様書を、ねこタワーのGitHubリポジトリに入れてほしい。

実装範囲:

- 独立したCPU対戦ボタン。
- オンライン待機中のCPU対戦、成立時のオンラインへの切替。
- 指示・仕様・構造・検証方法・再利用プロンプトをMarkdownで管理する。

## 継続開発

- 人間とAIが読みやすく、変更箇所を絞れる構造を重視する。
- コードを仕様の中心に据え、コメントでは理由・制約を補足する。
- AIが毎回全文を読み直さなくてよいよう、AGENTS.mdを入口にする。
- 異なるAIでも会話履歴なしに再開できるよう、仕様と設計判断を残す。
- 共通方針の原文はai-development-guidelines.mdに保存。
